# 🎬 MV Generator

音楽を解析して、ビート・音量・音の強さに合わせて
映像を自動生成するStreamlitアプリです。

## 主な機能

- MP3 / WAV / M4A / OGGのアップロード
- 複数画像のアップロード
- 音楽のBPM解析
- ビート解析
- 音量解析
- 音の強さ解析
- 自動ズーム
- カメラシェイク
- グリッチ
- フラッシュ
- スピードライン
- 色反転
- ランダム映像生成
- 16:9 / 9:16対応
- MP4出力

## ローカル実行

```bash
pip install -r requirements.txt
streamlit run app.py
